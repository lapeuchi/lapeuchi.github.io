데이터가 송수신되는 과정

위 이미지를 기준으로 설명하겠다.

OSI 7 계층과 TCP/IP4 계층은 데이터가 인터넷을 통해 어떻게 전달되는지 보여주는 모델이다.

두 모델 사이에 있는건 각 계층에서 사용하는 프로토콜이다.

데이터를 보내는 입장은 제일 아래 계층에서, 받는 입장은 제일 위 계층에서부터 시작한다는 것을 알고 있으면 좋다.

OSI 7 계층 (OSI 7 Layers)

OSI 7계층은 국제표준화기구(ISO)에서 데이터가 송수신되는 과정을 7개의 계층으로 나누어 정리한 것이다.
OSI 7 Layers가 현실에서 일어나는 네트워킹과는 완전히 대응되지 않지만, 프로토콜이나 기술들의 기반이 되기도 한다.

각 계층을 설명하기 전 다음과 같은 용어를 숙지해야 한다.

  • 노드(Node): 네트워크 상의 장치나 시스템을 의미하며, 데이터가 통신하는 과정에서 거치게 되는 각 지점 또는 컴퓨터 자체를 가리킨다. 즉, 네트워크를 구성하는 라우터, 스위치, 서버, 또는 PC 등 통신에 참여하는 모든 컴퓨터나 장치들이다.

  • 호스트(Host): 통신 데이터의 최종 목적지 또는 출발지인 최종 사용자 장치 자체

  1. 물리 계층
    데이터를 비트 단위의 전기신호로 만들어 송수신한다. 오로지 데이터를 전달하는 목적을 가지고 어떤 데이터인지, 어떤 에러가 있는지 등에 관여하지 않는다. 대표적인 장비는 통신 케이블, 리피터, 허브가 있다.

  2. 데이터링크 계층 패킷이 도착했을 때 MAC 주소를 통해 host에게 전달한다. 대표적인 장비는 브릿지, 스위치가 있다.

  3. Network Layer: 데이터 패킷의 라우팅 담당 서로 다른 네트워크에 위치하는 host 간에 데이터를 주고 받을 때 작동하며, 목적지까지 갈 수 있는 다양한 길들 중에 최단거리를 찾는 일 등을 한다. 목적지까지의 경로가 적합한지 확인하는 Routing, 각 장치를 고유하게 식별할 수 있게 하는 Logical addressing과 같은 처리를 담당한다. 대표적인 장비는 라우터이다.

  4. Transport Layer: 데이터 전송의 신뢰성 보장 이 레이어에서의 데이터 단위를 segment라고 하며, 완전한 메세지(complete message)를 end-to-end로 전달하는 역할을 한다. 또한 데이터 전송이 성공적으로 완료되었는지 확인하고, error가 발견되면 데이터를 다시 보내는(re-transmit) 역할을 한다. TCP와 UDP를 대표적인 예로 들 수 있다.

  5. Session Layer: 통신 세션 관리 이 레이어는 connection(연결) 유지, session의 유지 및 인증, 보안을 담당한다.

  6. Presentation Layer: 데이터 형식을 변환 이 레이어는 Translation Layer라고도 한다. Application Layer의 데이터를 네트워크에 전송하기 위해 요구되는 format으로 조작한다.

  7. Application Layer: 최종 사용자의 응용 프로그램과 직접적으로 관련되는 부분 최상위 계층으로서, 사용자/어플리케이션이 네트워크에 접속할 수 있게 해주는 계층이다. end system이 이메일과 같은 서비스를 제공받기 위해 어떤 형식으로 메세지를 주고 받아야하는지에 대한 프로토콜이 모여 있는 레이어이다. socket이나 port number가 이 레이어와 관련이 되어 있는 지식이다.
