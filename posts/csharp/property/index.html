프로퍼티 사용법

  • 클래스에 중괄호 있는 변수를 선언.
  • get{}과 set{}의 내용을 정의하는데..
    • get에는 반환을
    • set에는 get에서 반환받은 것을 value(키워드)로 대입연산
// 프로퍼티 선언 정의
public int Hp
{
		get { return hp; }
		set { hp = value; }
}

//public int Hp { get; set; } = 100;
