## Java란?

자바는 JCP에서 관리되는 자바 표준 스펙을 기준으로 여러 회사에서 개발되고 있다.

* 자바 표준 스펙
  * 자바의 설계도이자 문서.
  * 자바 커뮤니티 프로세스(JCP)를 통해 관리된다.

* 다양한 자바 구현 
  * 여러 회사에서 자바 표준 스펙에 맞춰 실제 작동하는 자바 프로그램을 개발한다.
  * 자바 구현들은 모두 표준 스펙에 맞도록 개발되어 있다. 오라클 Open JDK를 사용하다가 Amazon
    Corretto로 변경해도 대부분 문제 없이 동작한다. 차이점은 예를 들어 Amazon Corretto는 AWS에 최적화 되어있는 정도
  * 각 회사들은 대부분 다양한 OS에서 작동하는 버전의 자바도 함께 제공한다.
  

## Java 구동 원리

우리가 작성한 소스코드가 실행되는 과정

1. 우리가 작성한 .java 파일을 자바 컴파일러(javac)를 사용해 컴파일하면 .class 파일이 생성된다.
   * .class 파일은 빠른 오류 검출과 실행을 위해 우리가 작성한 코드를 바이트 코드로 변환한 것으로 이루어진다.
2. .class 파일을 자바(java) 프로그램로 실행하면 자바 가상 머신(JVM)이 실행되며 프로그램이 작동한다.
   
.java파일 작성 -> javac로 .class파일 생성 -> java 프로그램 실행 -> JVM으로 프로그램 작동

## 자바와 운영체제 독립성

일반적인 프로그램은 다른 운영체제에서 실행할 수 없다. 예를 들어 windows에서만 실행되는 게임인 발로란트가 있다고 하자. 발로란트를 다른 OS에서 못하는 이유는 윈도우 OS에서만 사용하는 명령어들로 구성되어 있기 때문에 다른 OS와 호환되지 않기 때문이다.

자바 개발자는 특정 OS에 맞추어 개발을 하지 않고, 자바 코드에만 집중할 수 있다.  
OS 호환성 문제는 자바가 해결한다. 컴파일된 자바 파일은 모든 자바 환경에서 실행할 수 있다.

윈도우 자바는 윈도우 OS가 사용하는 명령어들로 구성되어 있다. Mac 자바, 리눅스 자바도 본인의 OS가 사용하
는 명령어들로 구성되어 있다. 

개발자는 각 OS에 맞도록 자바를 설치하기만 하면 된다.
