## 컴포넌트 클래스와 일반 클래스의 구분

- 게임 오브젝트에 부착되는 컴포넌트를 컴포넌트 클래스, 그냥 메모리 상에만 있고 코드상에서만 다루어질 클래스를 일반 C#클래스로 구분할 수 있다.

### 구분의 이유

- MonoBehavior를 상속받는 게임 오브젝트에 컴포넌트로 부착될 클래스 이외에 일반적인 C# 클래스가 필요한 시점이 있다.

## 컴포넌트 클래스

- 유니티에서 C#스크립트를 생성하면 기본적으로 MonoBehaviour class를 상속받으며 Start()와 Update()가 생성된 채로 생성이된다.
- MonoBehaviour를 상속받으면 인스펙터창에서 Add Component버튼으로 부착될 수 있다.
    - 또한 MonoBehaviour(유니티 기능)의 다양한 기능을 사용할 수 있다.

## 일반 C# 클래스

- MonoBehaviour를 상속받지 않고 게임 오브젝트에 컴포넌트로 부착되지 않으며 코드 내에서만 동작하는 일반 클래스.
    - MonoBehavior의 기능을 사용하지 못함
- 씬에 배치될 필요가 없는 오브젝트 일 때 사용함.
- 인스팩터 창의 Add Component 버튼에서 검색을 해도 표시되지 않는다.
