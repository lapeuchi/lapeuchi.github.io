# 불리언, 소수, 문자열 형식

```csharp
using System

namespace CSharp
{
	class Program
	{
		bool b; 
		b = true;
		b = false;

		float f = 3.14f;
		
		double g = 2.2;
		
		char a = "a";
		string b = "214dsadsa";
	}
}
```

### boolean

bool(1byte) : 은 **true false** 두 값을 가질 수 있다.

1byte가 1bit보다 연산이 빨라서 bool은 bit단위가 아니다.

### 실수형 (소수)

float(4byte) : 3.14f; (기본적으로 소수를 입력할때 f를 입력하지 않으면 double로 인식)

double : float보다 정밀하고 크다.

### 문자, 문자열

char(2 byte) : 하나의 문자만 저장이 가능하다.

string(문자열) : 여러 문자(문자열)을 저장한다.
