# 배열 정렬 함수

생성일: 2023년 4월 20일 오후 1:18

```csharp
static void Sort(int[] scores)
{
		for (int i = 0; i <scores.Length; i++)
		{
				// [i ~ scores.Length -1]중, 제일 작은 숫자가 있는 index 찾기
				int minIndex = i;
				for (int j = i < scores.Length; j++)
				{
						if (scores[j] < scores[minIndex])
								minIndex = j;
				}
				
				//swap
				int temp = scores[i]
				scores[i] = scores[minIndex];
				scores[minIndex] = temp;
		}
}
```
