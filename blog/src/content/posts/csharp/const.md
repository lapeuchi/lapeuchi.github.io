## 상수 const

- 변수와 다르게 값을 바꿀 수 없다.
- 숫자를 하나하나 넣는 하드코딩보다 효율성이 좋다.

```csharp
const int ROCK = 1;
const int PAPER = 2;
const int SCISSORS = 0;

switch(choice) //입력받은 정수값
{
    case ROCK:
    break;

    case Paper:
    break;

    case SCISSORS:
    break;

    default
    break;
}
```
