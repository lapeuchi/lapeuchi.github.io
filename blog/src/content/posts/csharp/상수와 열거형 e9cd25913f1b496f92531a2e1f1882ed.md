# 상수와 열거형

## 상수 const

- 변수와 다르게 값을 바꿀 수 없다.
- 숫자를 하나하나 넣는 하드코딩보다 효율성이 좋다.

```csharp
const int ROCK = 1;
const int PAPER = 2;
const int SCISSORS = 0;

switch(choice) //입력받은 정수값
{
	case ROCK:
	break;

	case Paper:
	break;

	case SCISSORS:
	break;

	default
	break;
}
```

## 열거형

- 하나의 그룹
- 사용법 : enum 이름
- 

```csharp
enum Choise  
{
	 Rock = 1;
	 Paper = 2;
	 Scissors = 0;
}

switch(choice) //입력받은 정수
{
	case (int)Choice.Scissors:
	break;

	case (int)Choice.Rock:
	break;

	case (int)Choice.Paper:
	break;

	default
	break;
}

```
