# 데이터 연산

### 할당(대입) 연산(=)

좌변의 값을 복사하여 우변에 저장. 

```csharp
using System

namespace CSharp
{
	class Program
  {
		int hp = 100;
		// + - * / %
		hp = 2 * 100 + 1; //201
		//계산은 사칙연산의 규칙을 따른다
		
		int a = 100 % 3 // 1 나머지 연산
	
		int b = 2;
		b++;	// b = b + 1
		++b;  
		b--;  // b = b - 1
		--b;
		//부호가 앞이면 바로 계산되고 
		//뒤에 있으면 다음줄부터 계산된다.
		
		// < <= > >= (부등호) ==(같은가) !=(아닌가)
		bool c = hp < 100; // false hp < 100이 아님

		// &&(AND) || (OR) !(NOT)
		// d = 살아있는 고렙 유저인가요?
		bool d = isAlive && isHighLevel;
	
		// e = 살아있거나, 고렙이거나, 둘 중 하나인가요?
		bool e = isAlive || isHighLevel; 
	
		// f = 죽었나?
		bool f = !isAlive;
  }
}

```
