## 스택 메모리

- 굉장히 불안정하고 임시적으로 사용
- 함수를 실행하기 위한 메모장같은 존재
- 무조건 함수안에 선언되는 변수들은 무조건 스택 영역에 들어간다.'
- 함수 시작부터 끝까지 자기가 현재 어느 만큼의 스택 공간을 사용하는지 추적 → 알아서 메모리 관리를 함 → **신경 쓸 필요 없음**

### 스택을 들여다보면...

- 복사(struct)되는 타입은 실제 메모리(본체)가 들어간다.
- 참조(class)되는 타입은 주소가 들어간다.
    - 참조타입의 본체는 힙 영역에 들어간다.
        - **ref**를 사용할 때 본체가 스택에 있을 수 있음

## 힙 메모리

- 동적으로 할당
- 메모리가 할당되면 계속 쌓인다.
    - high language는 알아서 관리를 해준다.
    - c++ 경우 객체생성을 하고 delete()로 지워 줘야...

### plus

- 스택과 힙으로 구분이 되는것을 깊은복사라고 한다.
- Knight k = knight; : 참조 타입(스택에서 힙으로같은 본체를 가리킨다.)
- 

```csharp
//클래스는 참조형식.
Knight knight = new Knight()
//knight라고 선언하면 stack메모리에 knight라는 변수가 생기고
//new Knight()를 실행하는 순간 힙 메모리 영역에
//실제 Knight의 본체가 생성된다.
//stack 메모리속 kight 변수는 힙의 Knight를 참조한다.

```
