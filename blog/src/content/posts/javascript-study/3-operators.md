## 개요
기본적인 산술 연산, 할당 연산은 다른 언어와 같으니 서술하지 않겠다.

```js

console.log(1 == 1); // true
console.log(1 == '1'); // true
console.log(0 == ''); // true 
console.log(false == 0); // true
console.log(true == '1'); // true

console.log(5 === '5'); // '==='를 쓰면 타입이 다르면 false로 나온다. 다른 언어처럼 가능 웬만하면 이걸로 쓰자. 

```
