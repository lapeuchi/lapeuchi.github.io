## 개요

> 클래스 속 함수를 맴버 함수라고 한다.
클래스의 목적에 따라 기능과 호출시점을 생각해서 자유롭게 맴버 함수를 정의할 수 있는데
이와는 다르게 좀 특별한 함수가 있다.

바로 포스트의 주제인 "**생성자**"와 "**소멸자**"이다.
둘은 각각 **객체의 시작과 끝**을 알리는 함수이다.

## 생성자와 소멸자의 기본 형태

아래는 생성자와 소멸자를 선언, 정의하는 예제이다.
```cpp
class Knight
{
public:
    Knight(); // 생성자 선언
    ~Knight(); // 소멸자 선언 (이름 앞 '~')

    void Move(int x, int y);

public:
    int x;
    int y;
}

Knight::Knight() // 생성자 정의
{

}

Knight::~Knight() // 소멸자 정의
{

}
```
일반적인 함수를 선언하는 것과 비슷하다.
우선 일반적인 함수와 다르게 반환 형식을 지정하지 않는다. ~~(void도 아니다.)~~
생성자와 소멸자는 클래스와 동일한 이름으로 선언하고, 소멸자 앞에는 꼭 '*~*'를 붙여야 한다.

소멸자는 클래스별 단 하나만 선언할 수 있지만 생성자는 다양한 방법으로 여러개 선언이 가능하다.

## 접근 제어자에 따른 생성자와 소멸자
일반적으로 public에 선언하지만 상황에 따라 다르게 쓰는 것도 가능하다.

아래 표에 접근 제어자에 따른 생성자와 소멸자의 용도를 정리하였다. 

|접근 제어자|생성자|소멸자|용도|
|-----|---|---|---|
|public|일반적인 객체 생성|기본 소멸 가능|대부분의 경우|
|protected|상속 전용 객체 생성|자식 전용 파괴|추상 클래스, 인터페이스|
|private|외부 생성 제한|외부 소멸 제한|싱글턴, 팩토리, 자원 통제|
