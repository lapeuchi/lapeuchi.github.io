## 개요

클래스 속 함수를 맴버 함수라고 한다.
클래스의 목적에 따라 기능과 호출시점을 생각해서 자유롭게 맴버 함수를 정의할 수 있는데
이와는 다르게 좀 특별한 함수가 있다.

바로 포스트의 주제인 "**생성자**"와 "**소멸자**"이다.
둘은 각각 **객체의 시작과 끝**을 알리는 함수이다.

우리가 원할 때 호출하는 것이 아니다.
생성자는 객체가 생성될 때, 소멸자는 객체가 소멸될 때 호출된다.

생성자에는 객체가 생성될 때 필요한 코드를, (생성자에서 멤버변수를 초기화 한다던가)  
소멸자에는 객체가 소멸될 때 필요한 코드를 작성하면 된다. (힙에서 뭔가를 할당 해제를 한다던가)

## 생성자와 소멸자

생성자와 소멸자를 선언하는 건 일반적인 함수를 선언하는 것과 비슷하다. 형식은 다음과 같다.

1. 일반적인 함수와 다르게 **반환 형식을 지정하지 않는다.**
2. 생성자와 소멸자는 **클래스와 동일한 이름**으로 선언한다.  
3. 소멸자 앞에는 꼭 '**~**'를 붙여야 한다.

아래는 기본 생성자와 소멸자를 선언 및 정의하는 예제이다.
생성자와 소멸자의 호출 시점에 집중해보자.  

```cpp
class Knight
{
public: 
    // 기본 생성자 선언 (반환 형식은 적지 않고, 함수 이름은 클래스랑 똑같이)
    Knight();

    // 소멸자 선언 (기본 생성자 처럼 쓰는데, 앞에 ~ 붙이기)
    ~Knight(); 
}

// 기본 생성자 정의
Knight::Knight() 
{
    cout << "기본 생성자 호출!";
}

// 소멸자 정의
Knight::~Knight() 
{
    cout << "소멸자 호출!";
}

int main()
{
    Kinght k1; // [출력]: 기본 생성자 호출!
    
    return 0; // [출력]: 소멸자 호출!
}
```

k1이 생성되었을 때 생성자가 호출되고
main() 함수가 종료되어 스택 메모리에서 k1이 사라질 때 소멸자가 호출되었다.

소멸자는 위 예제처럼 받는 인자 없이 클래스 별 단 하나만 선언할 수 있다. 
그에 비해 생성자는 목적에 따른 오버로딩 선언이 가능하다.

생성자의 종류에 대한 내용은 다음 목차에 자세히 서술하겠다.

## 생성자의 종류

생성자는 다양한 목적을 가지고 정의할 수 있다.

아래 예제들은 주로 쓰는 방식들이다.

### 기본 생성자
아무 인자를 받지 않는다.

```cpp
class Knight
{
public:
    Knight() // 기본 생성자
    {
        cout << "기본 생성자 호출!";
    }
}

int main()
{
    Knight k1; // 출력: 기본 생성자 호출! (함수 호출 기호 "()" 없이 쓰면 기본 생성자가 호출됨)
    Knight k2(); // 출력: 기본 생성자 호출!
}
```

> 생성자를 단 하나도 정의하지 않으면 어떻게 될까?  
>> 컴파일 에러 같이 생기는 문제는 없다.  
>> 생성자를 명시적으로 만들지 않으면, 기본 생성자가 컴파일러에 의해 자동으로 만들어진다.   
>> 그러나 명시적으로 생성자를 하나라도 만들면 만들어지지 않는다.

```cpp
class Knight { }

int main()
{
    Knight k1; // 생성자가 없으면 컴파일러가 만든 기본 생성자를 암시적으로 호출한다. (객체가 생기면 무슨 방법을 써서라도 꼭 생성자를 호출한다.)
}
```

> 기본 생성자가 없고 다른 생성자는 있는데 기본 생성자를 호출하면 어떻게 될까?
>> 컴파일 에러가 생긴다.  
>> 기본 생성자가 없고 다른 생성자가 있으면 꼭 다른 생성자를 사용해서 객체를 생성해야 한다.
```cpp
class Knight 
{ 
public:
    int _hp;

    Knight(int hp) 
    {
        _hp = hp;
    }
}

int main()
{
    Knight k1; // 기본 생성자를 찾을 수 없어 컴파일 에러 발생.
    Knight k2(100); // 기본 생성자가 없고 다른 생성자가 있으면 꼭 다른 생성자를 사용해서 객체를 생성해야 한다.
}
```

### 기타 생성자
인자를 받아 변수를 초기화 하기 위해 사용한다.

```cpp
class Knight
{
public:
    int _hp;
    int _atk;
    // 일반적인 생성자 (초기화가 필요한 변수를 인자로 받아 초기화 할 수 있다.)
    Knight(int hp, int atk)
    {
        _hp = hp;
        _atk = atk;
    }
}

int main()
{
    Knight k1(100, 10);
}
```

> 인자가 하나인 생성자를 "타입 변환 생성자" 라고 부르기도 한다.
>> 인자 하나로 객체를 초기화 하는 걸 더불어 **클래스와 인자 타입 간 암시적 형변환을 가능하게 한다.**
```cpp
class Knight
{
public:
    int _hp;
    // 인자를 1개만 받는 생성자를 "타입 변환 생성자" 라고 하기도 한다.
    Knight(int hp) 
    {
        _hp = hp;
    }
}

void PrintInfo(Kinght k)
{
    cout << "hp: " << hp << endl;
}

int main()
{
    Knight k1 = 100; // 타입 변환 생성자
    
    Knight k2;
    k2 = 1000; // 컴파일 기준 k1, k2 둘다 Knight(int hp)를 호출한 것과 다름이 없다.

    PrintInfo(300); // _hp 300짜리의 객체가 생성된다. (출력 값: 300)
}
```
> 인자가 하나인 생성자를 일반적인 초기화 목적으로 쓰려고 한건데, 저런 목적으로 쓰려고 만든게 아닌데 컴파일러가 암시적으로 형변환 시키면 혼란스럽지 않을까?
>> explicit 키워드를 사용하면 된다. explicit는 한국어로 명시적인 이라는 뜻이다. 
>> 타입 변환 생성자의 기능을 뺀, 단순 초기화가 목적인 인자 하나인 생성자로 사용할 수 있게 해준다.
```cpp
class Knight
{
public:
    int _hp;
    // 인자를 1개만 받는 생성자를 "타입 변환 생성자" 라고 하기도 한다.
    explicit Knight(int hp) 
    {
        _hp = hp;
    }
}

void PrintInfo(Kinght k)
{
    cout << "hp: " << hp << endl;
}

int main()
{    
    Knight k1;
    k1 = 1000; // 컴파일 에러

    PrintInfo(300); // 컴파일 에러

    k1 = (Knight)1000; // 형변환을 명시적으로 하면 에러가 안남 

    PrintInfo((Knight)300); // 형변환을 명시적으로 하면 에러가 안남  
}
```

### 복사 생성자
자신의 참조 타입을 인자로 받는다.  
일반적으로 똑같은 데이터를 지닌 객체 생성을 목표로 사용한다. (말 그대로 복사)
```cpp
class Knight
{
public:
    // 복사 생성자 (자신의 참조 타입을 인자로 받음)
    // 일반적으로 똑같은 데이터를 지닌 객체가 생성되길 기대한다.
    Knight(const Knight& knight) 
    {
        _hp = knight.hp;
        _attack = knight._attack;
    }

    PrintStat()
    {
        cout << "공격력: " << _atk;
        cout << "체력: " << _hp;
    }

public:
    int _atk;
    int _hp;
}

int main()
{
    Kinght k1(100); // 출력: 기본 생성자 호출!
    k1._hp = 0;
    Kinght k2(k1);
    return 0; // 출력: 소멸자 호출!
}
```

## 접근 제어자에 따른 생성자와 소멸자
일반적으로 public에 선언하지만 상황에 따라 다르게 쓰는 것도 가능하다.

아래 표에 접근 제어자에 따른 생성자와 소멸자의 용도를 정리하였다. 

|접근 제어자|생성자|소멸자|용도|
|-----|---|---|---|
|public|일반적인 객체 생성|기본 소멸 가능|대부분의 경우|
|protected|상속 전용 객체 생성|자식 전용 파괴|추상 클래스, 인터페이스|
|private|외부 생성 제한|외부 소멸 제한|싱글턴, 팩토리, 자원 통제|
