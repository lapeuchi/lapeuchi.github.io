## 프로토콜

프로토콜은 장치와 시스템 간에 정보를 어떻게 주고받을지 정해둔 규칙과 표준을 말한다.

프로토콜은 인터넷에서 통신과 데이터 교환을 가능하게 하는 데 아주 중요한 역할을 한다.

## 프로토콜의 기본 요소 3가지
구문(Syntax) : 전송하고자 하는 데이터의 형식(Format), 부호화(Coding), 신호레벨(Signal Level) 등을 규정
의미(Semantics) : 두 기기 간의 효율적이고 정확한 정보 전송을 위한 협조 사항과 오류 관리를 위한 제어 정보를 규정
시간(Timing) : 두 기기 간의 통신 속도, 메시지의 순서 제어 등을 규정

## 프로토콜의 종류
인터넷 통신에서는 다양한 프로토콜이 사용된다. 기본적인 IP, TCP, UDP 부터 DNS, HTTP, SSL/TLS등 다양한 프로토콜이 있다.

* IP: 패킷을 정확한 목적지로 보내줌.

* TCP: 패킷이 손실되지 않고, 순서대로 잘 도착하도록 확인하는 역할

* UDP: TCP의 반대지만 빠르다. (실시간 멀티플레이 게임이나 영상 스트리밍에 사용한다.)

* [**DNS**](what-is-dns): 도메인 이름을 IP 주소로 변환한다. (도메인 이름은 아래 참조.)

* [**HTTP**](what-is-http) : 웹 브라우저와 웹 서버 간에 데이터를 주고받기 위한 웹의 기본 통신 규칙, 웹페이지(HTML)와 같은 하이퍼미디어 문서를 전송하는 데 사용

* SSL/TLS: 데이터를 암호화해서 안전하게 주고받는 규칙 

표준화된 프로토콜을 사용하면,  서로 다른 회사에서 만든 장치나 시스템도 문제없이 소통할 수 있다는게 큰 장점이다.
예를 들어 A 회사가 만든 웹 브라우저도 B 회사가 만든 웹 서버와 통신할 수 있는데, 둘 다 HTTP 규칙만 지키면 된다.
