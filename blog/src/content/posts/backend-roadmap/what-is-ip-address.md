## IP 주소
우리가 택배나 우편을 보낼 때 우편번호랑 주소를 알아야한다.

비슷하게도 컴퓨터에 데이터를 전송하려면 IP 주소를 알아야 한다.

IP 주소는 네트워크에 연결된 각 장치에 부여되는 고유한 식별자이다. 데이터가 올바른 목적지로 가도록 경로를 지정할 때 사용한다.

IP 주소는 크게 두 종류가 있다. 바로 IPv4와 IPv6이다. 아래에서 자세히 알아보자

## IPv4
IPv4는 Internet Protocol version 4의 약자이다. 전세계적으로 사용된 인터넷 프로토콜의 시초이다.

32비트 방식으로, 8비트씩 4자리로 되어 있다. 각 자리는 온점(.)으로 구분한다. ex) 1.1.1.1, 73.227.130.85, 114.129.255.255

IPv4는 0~2^32개, 약 42억 9천 개의 주소를 가질 수 있는데, 세계적으로 사용중인 IP 갯수가 급증하면서 주소가 고갈될 위기에 처해있다. 이를 해결하기 위해 나온 것이 아래에서 설명할 IPv6이다.

## IPv6
IPv6는 IPv4의 주소체계를 128비트 크기로 확장한 차세대 인터넷 프로토콜 주소이다.

16비트씩 8자리로 각 자리는 콜론(:)으로 구분한다. ex) 2001:0DB8:1000:0000:0000:0000:1111:2222

네트워크 속도, 보안성 등 여러면에서 IPv4에 비해 좋다고 한다. 

## IPv4 - 사설 아이피와 공인 아이피

* 공인 IP 주소 (Public IP Address)
인터넷상에서 전 세계적으로 유일하게 식별되는 주소. ISP가 사용자에게 할당하며, 외부 네트워크와 통신할 때 사용된다. ISP는 인터넷 서비스 제공업체를 뜻하고 KT SK브로드밴드 이런 회사를 말한다.

* 사설 IP 주소 (Private IP Address)
공유기 등 내부 네트워크(로컬 네트워크)에서 사용되는 주소. 인터넷에서 라우팅되지 않으며, 동일한 IP 주소를 다른 네트워크에서 중복하여 사용할 수 있다.

특정한 공유기(집안에서 라우터 역할)에 연결되었을 때 그 공유기에 대표되는 IP 주소가 있고 그 IP 주소 아래에 할당되는 것들이 사설 IP이다.

## 터미널로 내 컴퓨터의 IP 주소 알아내기
cmd를 켜서 `ipconfig`라고 명령어를 입력해보자 (mac은 `ipconfig getifaddr en0`)

IPv4 주소를 보면 대부분 192.168.~~~.~~~ 이런 식으로 출력된다.

우리가 명령어를 입력해 출력된 건 IPv4 주소이자 사설 아이피이다.
