## IP 주소
우리가 택배나 우편을 보낼 때 우편번호랑 주소를 알아야한다.

비슷하게도 컴퓨터에 데이터를 전송하려면 IP 주소를 알아야 한다.

IP 주소는 네트워크에 연결된 각 장치에 부여되는 고유한 식별자이다. 데이터가 올바른 목적지로 가도록 경로를 지정할 때 사용한다.

IP 주소는 크게 두 종류가 있다. 바로 IPv4와 IPv6이다. 아래에서 자세히 알아보자

## IPv4

cmd를 켜서 `ipconfig`라고 명령어를 입력해보자 (mac은 `ipconfig getifaddr en0`)

대부분 192.168.~~~.~~~ 이런 식으로 출력된다.

우리가 명령어를 입력해 출력된 건 IPv4 주소이자 사설 아이피이다.

특정한 공유기(집안에서 라우터 역할)에 연결되었을 때 그 공유기에 대표되는 IP 주소가 있고 그 IP 주소 아래에 할당되는 것들이 사설 IP이다.
